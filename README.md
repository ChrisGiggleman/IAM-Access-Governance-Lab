# IAM Access Governance Lab

A hands-on Identity and Access Management (IAM) lab focused on identity administration, access governance, authentication, role-based access control, identity lifecycle management, and security analysis.

The purpose of this project is to build practical IAM skills using Microsoft Entra ID concepts, PowerShell automation, access-review workflows, and realistic enterprise identity scenarios.

---

## Project Goals

This lab is designed to develop hands-on experience with:

- Identity and Access Management (IAM)
- Microsoft Entra ID
- Active Directory concepts
- User and group administration
- Role-Based Access Control (RBAC)
- Principle of Least Privilege
- Joiner, Mover, and Leaver (JML) lifecycle management
- Multi-Factor Authentication (MFA)
- Conditional Access
- Access reviews and certifications
- Privileged access concepts
- Identity governance
- PowerShell automation
- Security and authentication analysis

---

## Lab Scenarios

The project will include realistic IAM scenarios such as:

### Joiner
Provisioning access for a new employee based on their department and job role.

### Mover
Reviewing and modifying access when an employee changes departments or responsibilities.

### Leaver
Reviewing the deprovisioning process for an employee leaving the organization.

### Access Review
Identifying stale, unnecessary, excessive, or inappropriate access and documenting remediation decisions.

### Privileged Access
Reviewing elevated permissions and validating whether privileged access has a legitimate business justification.
